# Finance Tracker

A personal finance app for Android that installs from the browser (a Progressive Web App).
Track income and expenses, set budgets, and plan your way out of debt.

**Your data stays on your phone.** Nothing you enter is stored in this repository or sent to any server.

## Use it

Open https://aksubudhi123.github.io/finance-tracker/ in Chrome, then use the menu ⋮ → **Add to Home screen**.

## Develop

```bash
npm install
npm run dev     # local preview
npm test        # unit tests
npm run build   # production build in dist/
```

Every push to `main` runs the tests and publishes the app to GitHub Pages automatically.
